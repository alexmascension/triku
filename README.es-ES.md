Triku (erizo en euskera) es un método de selección de características diseñado para scRNA-seq.

¡Consulta la [documentación](https://triku.readthedocs.io/en/latest/) para aprender más sobre triku!
¡Puedes visitar los notebooks en nuestro [repositorio de notebooks](https://github.com/alexmascension/triku_notebooks)!
